House rules
  • Each row is a plate that holds one word, up to 5 letters, left to right with no gaps.
  • Put the letter at either end of a plate, or drop it on a letter already there to swap it.
  • When a plate spells a word of 3 or more letters, it's served and you score. Playing with two, it's then the other person's turn.
  • Keep turning a plate into new words, each one another course: TIN → TINE → TILE → TILED. Every course adds a bonus.
  • A plate with only one or two letters on it isn't a dish yet, so keep going.
  • The Q always comes with its U. The QU plate takes one spot but spells two letters, so QU·I·T is QUIT.
  • Serve something that isn't a word and it gets sent back: you lose 25 and the plate's courses start over. The letters stay, so you or the other player can fix it on a later turn.
  • Don't want a letter? Skip it. It's gone for good, and with two players your turn ends.
  • Each word can be served only once per game. If a spot would make a word that's already been served, the letter can't go there.
  • Spell one of today's specials for a big bonus.
  • The game ends when all 40 letters are used.
  • The Daily Table deals everyone the same letters and specials each day. You get one try, with no undo, and a fresh table at midnight.

Scoring: add up the letter values, then ×10 for a 3-letter word, ×15 for 4, ×25 for 5, and ×35 for a 6-letter Qu word. Each extra course adds 15. Specials add 100 (4 letters) or 200 (5 letters).
